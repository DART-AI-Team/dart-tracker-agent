# DART Service Module

이 모듈은 수집 적재 완료된 공시 정보를 기반으로, AI 에이전트를 구동하여 정정공시와 원본 공시를 비교 및 대조하고 가치 있는 분석 리포트를 생성하는 핵심 비즈니스 로직을 담당합니다.

---

## 🏗️ 폴더 및 파일 구조

```text
app/service/
├── README.md               # 모듈 문서
├── __init__.py             # 패키지 진입점 (servicer() 래퍼 제공)
└── modules/                # 하위 비즈니스 로직 모듈
    ├── receiver.py         # 공시 정보 수신 및 DB 매핑 데이터(정정본, 원본) 조회
    └── agent/              # AI 분석 에이전트 패키지
        ├── agent.py        # 대조 및 요약 리포트 생성 (analyst() 노드)
        ├── graph.py        # LangGraph 워크플로우 구성 및 관리 (build_graph())
        └── state.py        # 에이전트 간 전달되는 상태 정의 (AgentState)
```

## 🎯 설계 의도 (Design Intent)

### 1. 관심사 분리를 통한 의존성 완화
* **수집(Ingestion)과의 분리**: DB에 데이터를 밀어 넣는 수집기(`ingestor`)와 수집된 데이터를 해석하는 서비스(`servicer`)를 물리적으로 분리하여 개별 수정 및 배포가 용이하도록 설계했습니다.

### 2. 이벤트 기반 온디맨드(On-Demand) 실행
* **`receiver.py`**: DB 적재가 완료되었다는 트리거 신호를 받았을 때만 동작하여 이전 원본 문서를 DB에서 능동적으로 가져옵니다. 
* 이를 통해 불필요한 AI 에이전트 상시 구동을 방지하고 **토큰 요금을 극적으로 절감**합니다.

### 3. 확장성 높은 LangGraph 에이전트 구조
* **`agent/`**: 단순 프롬프트 호출에 그치지 않고 LangGraph 구조(`graph.py`, `state.py`)를 적용하여 정정 전후 수치 유효성 검증, 조건부 분석 등 향후 고도화된 비즈니스 룰을 그래프 상의 노드로 쉽게 확장할 수 있도록 대비했습니다.
